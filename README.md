# Dronebreaker · web

Páginas públicas del juego Dronebreaker para las fichas de App Store y Google Play: política de privacidad, soporte y portada. Se publican con GitHub Pages desde la rama `main`.

- Política de privacidad: `privacy/` (español y, debajo, inglés en `#en`)
- Soporte: `support/`

Si el juego cambia lo que recoge (analítica, compras, cuentas…), hay que actualizar `privacy/index.html` y su fecha antes de publicar esa versión.
